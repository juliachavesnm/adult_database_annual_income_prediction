# Adult Annual Income Prediction

A machine learning project for predicting annual income from demographic and socioeconomic data using the **Adult dataset**.

## Overview

This project investigates the prediction of annual income based on sociodemographic characteristics. Four machine learning algorithms are compared using preprocessing techniques to prepare the data for classification. The goal was to compare different machine learning approaches for income classification and gain practical experience with data preprocessing, supervised learning, and model evaluation.

## Models

The following algorithms are evaluated:

* Logistic Regression
* Support Vector Machine (SVM)
* Random Forest
* XGBoost
